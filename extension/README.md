# PromptMatch Collector

The collector is opt-in. It watches only the prompt composer on ChatGPT, Gemini and Claude and sends prompt text after a user submits it.

Data sent: random collector key, prompt text, provider, timestamp.
Not sent: account identity, cookies, AI responses, browsing history.

To install manually: unzip, open chrome://extensions, enable Developer mode, choose Load unpacked and select this folder.
